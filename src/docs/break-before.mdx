## Ejemplos

### Ejemplo básico

Utiliza utilidades como `break-before-column` y `break-before-page` para controlar cómo debe comportarse un salto de columna o página antes de un elemento:

```html
<!-- [!code classes:break-before-column] -->
<div class="columns-2">
  <p>Well, let me tell you something, ...</p>
  <p class="break-before-column">Sure, go ahead, laugh...</p>
  <p>Maybe we can live without...</p>
  <p>Look. If you think this is...</p>
</div>
```
