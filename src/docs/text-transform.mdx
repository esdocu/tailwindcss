## Ejemplos

### Texto en mayúsculas

Usa la utilidad `uppercase` para convertir el texto de un elemento en mayúsculas:

<Figure>

<Example>
  {
    <p className="text-center text-lg font-medium text-gray-900 uppercase dark:text-gray-200">
      El veloz zorro marrón salta sobre el perro perezoso.
    </p>
  }
</Example>

```html
<!-- [!code classes:uppercase] -->
<p class="uppercase">El veloz zorro marrón ...</p>
```

</Figure>

### Texto en minúsculas

Usa la utilidad `lowercase` para convertir el texto de un elemento en minúsculas:

<Figure>

<Example>
  {
    <p className="text-center text-lg font-medium text-gray-900 lowercase dark:text-gray-200">
      El veloz zorro marrón salta sobre el perro perezoso.
    </p>
  }
</Example>

```html
<!-- [!code classes:lowercase] -->
<p class="lowercase">El veloz zorro marrón ...</p>
```

</Figure>

### Capitalizar texto

Usa la utilidad `capitalize` para poner en mayúscula la primera letra de cada palabra en el texto de un elemento:

<Figure>

<Example>
  {
    <p className="text-center text-lg font-medium text-gray-900 capitalize dark:text-gray-200">
      El veloz zorro marrón salta sobre el perro perezoso.
    </p>
  }
</Example>

```html
<!-- [!code classes:capitalize] -->
<p class="capitalize">El veloz zorro marrón ...</p>
```

</Figure>

### Restablecer mayúsculas y minúsculas

Usa la utilidad `normal-case` para conservar las mayúsculas y minúsculas originales del texto de un elemento, típicamente usada para restablecer la capitalización en diferentes breakpoints:

<Figure>

<Example>
  {
    <p className="text-center text-lg font-medium text-gray-900 normal-case dark:text-gray-200">
      El veloz zorro marrón salta sobre el perro perezoso.
    </p>
  }
</Example>

```html
<!-- [!code classes:normal-case] -->
<p class="normal-case">El veloz zorro marrón ...</p>
```

</Figure>
