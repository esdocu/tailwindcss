## Ejemplos

### Ejemplo básico

Utiliza utilidades como `break-after-column` y `break-after-page` para controlar cómo debe comportarse un salto de columna o página después de un elemento:

```html
<!-- [!code classes:break-after-column] -->
<div class="columns-2">
  <p>Well, let me tell you something, ...</p>
  <p class="break-after-column">Sure, go ahead, laugh...</p>
  <p>Maybe we can live without...</p>
  <p>Look. If you think this is...</p>
</div>
```
