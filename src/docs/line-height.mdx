Cada utilidad de tamaño de fuente también establece una altura de línea por defecto cuando no se proporciona una. Puedes obtener más información sobre estos valores y cómo personalizarlos en la [documentación de font-size](/docs/font-size).

### Eliminar el interlineado

Utiliza la utilidad `leading-none` para establecer la altura de línea de un elemento igual a su tamaño de fuente:

<Figure>

<Example>
  {
    <p className="mx-auto max-w-2xs text-2xl leading-none text-gray-900 dark:text-gray-200">
      El veloz zorro marrón salta sobre el perro perezoso.
    </p>
  }
</Example>

```html
<!-- [!code classes:leading-none] -->
<p class="text-2xl leading-none ...">El veloz zorro marrón...</p>
```

</Figure>
