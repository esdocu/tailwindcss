## Ejemplos

### Cambiar el tamaño en todas las direcciones

Utiliza `resize` para hacer que se pueda cambiar el tamaño de un elemento tanto horizontal como verticalmente:

<Figure hint="Arrastra el tirador del área de texto en la demostración para ver el comportamiento esperado">

<Example>
  {
    <textarea
      rows="2"
      className="mx-auto block w-80 resize rounded-md p-2 text-sm text-gray-950 outline-1 outline-gray-900/10 focus:outline-2 focus:outline-gray-900 dark:bg-gray-950/25 dark:text-white dark:outline-1 dark:outline-white/5 dark:focus:outline-white/20"
    ></textarea>
  }
</Example>

```html
<!-- [!code classes:resize] -->
<textarea class="resize rounded-md ..."></textarea>
```

</Figure>
