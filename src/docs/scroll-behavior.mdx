## Ejemplos

### Uso de desplazamiento suave (smooth scrolling)

Utiliza la utilidad `scroll-smooth` para habilitar el desplazamiento suave dentro de un elemento:

```html
<!-- [!code classes:scroll-smooth] -->
<html class="scroll-smooth">
  <!-- ... -->
</html>
```

Establecer `scroll-behavior` solo afecta a los eventos de desplazamiento activados por el navegador.

### Uso de desplazamiento normal

Utiliza la utilidad `scroll-auto` para volver al comportamiento de desplazamiento predeterminado del navegador:

```html
<!-- [!code classes:scroll-auto] -->
<html class="scroll-smooth md:scroll-auto">
  <!-- ... -->
</html>
```
