## Ejemplos

### Ejemplo básico

Usa utilidades `zoom-<number>` como `zoom-75` y `zoom-125` para escalar un elemento usando la propiedad de CSS `zoom`:

```html
<!-- [!code classes:zoom-75,zoom-100,zoom-125] -->
<div class="zoom-75 ...">
  <!-- ... -->
</div>
<div class="zoom-100 ...">
  <!-- ... -->
</div>
<div class="zoom-125 ...">
  <!-- ... -->
</div>
```
