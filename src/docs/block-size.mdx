### Coincidir con el viewport

Utiliza la utilidad `block-screen` para hacer que un elemento ocupe todo el tamaño de bloque del viewport:

```html
<!-- [!code classes:block-screen] -->
<div class="block-screen">
  <!-- ... -->
</div>
```

### Coincidir con el viewport dinámico

Utiliza la utilidad `block-dvh` para hacer que un elemento ocupe todo el tamaño de bloque del viewport, el cual cambia a medida que la interfaz de usuario del navegador se expande o se contrae:

```html
<!-- [!code classes:block-dvh] -->
<div class="block-dvh">
  <!-- ... -->
</div>
```

### Coincidir con el viewport grande

Utiliza la utilidad `block-lvh` para establecer el tamaño de bloque de un elemento al tamaño más grande posible del viewport:

```html
<!-- [!code classes:block-lvh] -->
<div class="block-lvh">
  <!-- ... -->
</div>
```

### Coincidir con el viewport pequeño

Utiliza la utilidad `block-svh` para establecer el tamaño de bloque de un elemento al tamaño más pequeño posible del viewport:

```html
<!-- [!code classes:block-svh] -->
<div class="block-svh">
  <!-- ... -->
</div>
```
