Esto es útil para aplicar sombras a formas irregulares, como texto y elementos SVG. Para aplicar sombras a elementos regulares, probablemente prefieras usar la propiedad [sombra de caja (box-shadow)](/docs/box-shadow) en su lugar.

```html
<!-- [!code classes:drop-shadow-xl,drop-shadow-xl/25,drop-shadow-xl/50] -->
<svg class="fill-white drop-shadow-xl ...">...</svg>
```

</Figure>

Las opacidades predeterminadas de las sombras proyectadas son bastante bajas (15% o menos), por lo que aumentar la opacidad (por ejemplo, al 50%) hará que las sombras proyectadas sean más pronunciadas.

```html
<!-- [!code classes:drop-shadow-cyan-500/50,drop-shadow-indigo-500/50] -->
<svg class="fill-cyan-500 drop-shadow-lg drop-shadow-cyan-500/50 ...">...</svg>
```

</Figure>

De forma predeterminada, las sombras coloreadas tienen una opacidad del 100%, pero puedes ajustarla utilizando el modificador de opacidad.

### Eliminar una sombra proyectada

Utiliza la utilidad `drop-shadow-none` para eliminar una sombra proyectada existente de un elemento:

<Figure>

```html
<!-- [!code classes:dark:drop-shadow-none] -->
<svg class="drop-shadow-lg dark:drop-shadow-none">
  <!-- ... -->
</svg>
```

</Figure>
