### Usar una variable CSS

Utiliza la sintaxis <code>list-image-{'(<custom-property>)'}</code> para controlar la imagen de marcador para elementos de lista usando una variable CSS:

```html
<!-- [!code classes:list-image-(--my-list-image)] -->
<ul class="list-image-(--my-list-image)">
  <!-- ... -->
</ul>
```

Esto es solo un atajo para <code>list-image-{'[var(<custom-property>)]'}</code> que agrega la función `var()` por ti automáticamente.

### Eliminar una imagen de marcador

Utiliza la utilidad `list-image-none` para eliminar una imagen de marcador existente de los elementos de lista:

```html
<!-- [!code classes:list-image-none] -->
<ul class="list-image-none">
  <!-- ... -->
</ul>
```
