## Ejemplos

### Ejemplo básico

Utiliza la sintaxis `content-[<value>]`, junto con las variantes `before` y `after`, para establecer el contenido de los pseudo-elementos `::before` y `::after`:

<Figure>

<Example>
  {
    <div className="mx-auto w-full max-w-md text-gray-500 dark:text-gray-400">
      Una mayor resolución significa más que solo una imagen de mejor calidad. Con una pantalla Retina 6K,{" "}
      <a
        href="https://www.apple.com/pro-display-xdr/"
        className="font-medium text-blue-600 after:text-sm after:font-bold after:content-['_↗'] dark:text-sky-400"
        target="_blank"
      >
        Pro Display XDR
      </a>{" "}
      te brinda casi un 40 por ciento más de espacio de pantalla que una pantalla 5K.
    </div>
  }
</Example>

```html
<!-- [!code classes:after:content-['_↗']] -->
<!-- prettier-ignore -->
<p>Una mayor resolución significa más que solo una imagen de mejor calidad. Con una pantalla Retina 6K,
<a class="text-blue-600 after:content-['_↗']" href="...">Pro Display XDR</a> te brinda casi un 40 por ciento
más de espacio de pantalla que una pantalla 5K.</p>
```

</Figure>

### Referenciar el valor de un atributo

Utiliza la sintaxis `content-[attr(<name>)]` para hacer referencia a un valor almacenado en un atributo utilizando la función CSS `attr()`:

<Figure>

<Example>
  {
    <p
      before="Hola Mundo"
      className="text-center font-semibold text-gray-900 before:content-[attr(before)] dark:text-gray-200"
    />
  }
</Example>

```html
<!-- [!code classes:before:content-[attr(before)]] -->
<p before="Hola Mundo" class="before:content-[attr(before)] ...">
  <!-- ... -->
</p>
```

</Figure>

### Usar espacios y guiones bajos

Dado que el espacio en blanco denota el final de una clase en HTML, reemplaza cualquier espacio en un valor arbitrario con un guion bajo:

<Figure>

<Example>
  {<p className="text-center font-semibold text-gray-900 before:content-['Hola_Mundo'] dark:text-gray-200" />}
</Example>

```html
<!-- [!code classes:before:content-['Hola_Mundo']] -->
<p class="before:content-['Hola_Mundo'] ..."></p>
```

</Figure>

Si necesitas incluir un guion bajo real, puedes hacerlo escapándolo con una barra invertida:

<Figure>

<Example>
  {<p className="text-center font-semibold text-gray-900 before:content-['Hola\_Mundo'] dark:text-gray-200" />}
</Example>

```html
<!-- [!code classes:before:content-['Hola\_Mundo']] -->
<p class="before:content-['Hola\_Mundo']"></p>
```

</Figure>

### Usar una variable CSS

Utiliza la sintaxis `content-(<custom-property>)` para controlar el contenido de los pseudo-elementos `::before` y `::after` utilizando una variable CSS:

```html
<!-- [!code classes:content-(--my-content)] -->
<p class="content-(--my-content)"></p>
```

Esta es solo una abreviatura de `content-[var(<custom-property>)]` que agrega la función `var()` automáticamente por ti.
