Hay muchos bloques de interfaz de usuario en Tailwind Plus que necesitan JavaScript para ser realmente útiles, como diálogos, menús desplegables, paletas de comandos y más. Y a menos que seas usuario de React o Vue, usar esos bloques de interfaz de usuario siempre ha significado escribir todo ese JavaScript complicado por ti mismo.

Pues hoy eso finalmente cambia: **cada bloque de interfaz de usuario en Tailwind Plus ahora es completamente funcional, accesible e interactivo**, incluidos los ejemplos de HTML puro.

Ahora puedes usar cualquier [menú desplegable](https://tailwindcss.com/plus/ui-blocks/application-ui/elements/dropdowns), [paleta de comandos](https://tailwindcss.com/plus/ui-blocks/application-ui/navigation/command-palettes), [diálogo](https://tailwindcss.com/plus/ui-blocks/application-ui/overlays/modal-dialogs), [panel lateral](https://tailwindcss.com/plus/ui-blocks/application-ui/overlays/drawers) y más en cualquier proyecto en el que estés trabajando, sin necesidad de un framework de JavaScript.

---

## Sin necesidad de framework

Para lograr esto, creamos `@tailwindplus/elements`, una biblioteca que lanzamos exclusivamente para clientes de [Tailwind Plus](https://tailwindcss.com/plus).

Elements es una colección de [elementos personalizados](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements) headless que encapsulan todo el comportamiento complejo necesario para construir interfaces de usuario interactivas y personalizadas usando solo HTML, y se pueden diseñar de la manera que desees utilizando clases de utilidad o CSS personalizado.

En lugar de estar acoplados a un framework de JavaScript específico, estos elementos personalizados funcionan en cualquier lugar donde puedas usar una etiqueta `<script>`:

```html
/* [!code filename:index.html] */
<script src="https://cdn.jsdelivr.net/npm/@tailwindplus/elements@1" type="module"></script>
```

Para dar soporte a todos los bloques de interfaz de usuario en Tailwind Plus, incluimos las siguientes primitivas en este primer lanzamiento de Elements:

- [Autocomplete](https://tailwindcss.com/plus/ui-blocks/documentation/autocomplete) — para construir elementos como [Comboboxes](https://tailwindcss.com/plus/ui-blocks/application-ui/forms/comboboxes) personalizados.
- [Command palette](https://tailwindcss.com/plus/ui-blocks/documentation/command-palette) — para construir [Paletas de comandos](https://tailwindcss.com/plus/ui-blocks/application-ui/navigation/command-palettes) personalizadas.
- [Dialog](https://tailwindcss.com/plus/ui-blocks/documentation/dialog) — para construir [Diálogos modales](https://tailwindcss.com/plus/ui-blocks/application-ui/overlays/modal-dialogs) personalizados, [Paneles laterales](https://tailwindcss.com/plus/ui-blocks/application-ui/overlays/drawers) y más.
- [Disclosure](https://tailwindcss.com/plus/ui-blocks/documentation/disclosure) — para construir secciones de [Preguntas frecuentes (FAQ)](https://tailwindcss.com/plus/ui-blocks/marketing/sections/faq-sections#component-8699d80b13ef524eb573e54b4d4b89d1) colapsables, menús móviles en [Barras de navegación](https://tailwindcss.com/plus/ui-blocks/application-ui/navigation/navbars) y más.
- [Dropdown menu](https://tailwindcss.com/plus/ui-blocks/documentation/dropdown-menu) — para construir [Menús desplegables](https://tailwindcss.com/plus/ui-blocks/application-ui/elements/dropdowns) personalizados, por supuesto.
- [Popover](https://tailwindcss.com/plus/ui-blocks/documentation/popover) — para construir [Menús flotantes](https://tailwindcss.com/plus/ui-blocks/marketing/elements/flyout-menus) personalizados y más.
- [Select](https://tailwindcss.com/plus/ui-blocks/documentation/select) — para construir [Menús de selección](https://tailwindcss.com/plus/ui-blocks/application-ui/forms/select-menus#component-8298198b136afab3bb19391ae716077f) personalizados.
- [Tabs](https://tailwindcss.com/plus/ui-blocks/documentation/tabs) — para construir pestañas personalizadas, como las que usamos en [Áreas de texto](https://tailwindcss.com/plus/ui-blocks/application-ui/forms/textareas#component-532d35bcb49664c16a4f877d71658b12) y [Vistas generales de productos](https://tailwindcss.com/plus/ui-blocks/ecommerce/components/product-overviews#component-13a89c2dc50a31afd66541dc28fa3c13) personalizadas.

Si eres cliente de Tailwind Plus, dirígete a la nueva [documentación de Elements](https://tailwindcss.com/plus/ui-blocks/documentation/elements) para obtener más información sobre cómo funciona todo y ver algunos ejemplos.

## Aprovechando la web moderna

Nos apoyamos en muchas características modernas de la plataforma para mantener a Elements lo más ligero y nativo posible.

- [Elementos personalizados](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements) como una abstracción de componentes multiplataforma.
- [El atributo `popover`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/popover) para gestionar superposiciones y ventanas emergentes con renderizado automático en la capa superior (top-layer) junto con [`beforetoggle`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/beforetoggle_event) para controlar las transiciones.
- [Elementos `<dialog>` nativos](https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement) para captura de foco y renderizado en la capa superior.
- [Comandos invocadores](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_Commands_API) para gestionar de forma declarativa elementos interactivos, como alternar una divulgación (disclosure) personalizada.
- [`ElementInternals`](https://developer.mozilla.org/en-US/docs/Web/API/ElementInternals) para hacer que nuestros controles de formulario personalizados funcionen como controles de formulario nativos.

También incluimos los polyfills necesarios para estas características para asegurarnos de que Elements funcione en todos los mismos [navegadores compatibles con Tailwind CSS v4.0](https://tailwindcss.com/docs/compatibility#browser-support). Esto significa que Elements solo se reducirá de tamaño a medida que estas características modernas de la plataforma estén más disponibles.
